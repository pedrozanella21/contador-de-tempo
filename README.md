# Contador de Tempo ⏱️

Página que mostra, ao vivo, há quanto tempo algo começou — em dias, horas, minutos e segundos.

Comecei com um contador simples dos meus dias de treino de Muay Thai e evoluí para vários contadores que a própria pessoa pode criar.

🔗 **Ver online:** https://pedrozanella21.github.io/contador-de-tempo/

## Funcionalidades

- Contagem ao vivo, atualizada a cada segundo
- Adicionar contadores com nome e data de início
- Remover contadores
- Os contadores ficam salvos no navegador (localStorage)
- Layout responsivo, funciona no celular

## Tecnologias

- HTML
- CSS (grid, layout responsivo)
- JavaScript puro (manipulação do DOM, datas, localStorage)

## Como rodar

Não precisa instalar nada: baixe o `index.html` e abra no navegador.

## O que aprendi

- Calcular diferença entre datas sem erro de fuso horário
- Atualizar a tela em tempo real com `setInterval`
- Salvar dados no navegador com `localStorage`
